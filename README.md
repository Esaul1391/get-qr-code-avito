# Codes Harvester DEV

Изолированная копия расширения и локального backend для разработки и безопасного тестирования. Эталонное приложение из `/home/esaul/ap_from_br` продолжает работать независимо.

Проект собирает заказы, объявления и отзывы из личного кабинета Avito. Для заказов backend создаёт PNG-этикетки со штрихкодом Code 128. Несмотря на старое имя проекта, QR-коды здесь не используются.

## Чем DEV-копия отделена от эталона

| Компонент | Эталон | Текущая DEV-копия |
|---|---|---|
| Расширение | `Codes Harvester` | `Codes Harvester DEV`, значок `DEV` |
| Backend | `127.0.0.1:8000` | `127.0.0.1:8011` |
| Native Messaging Host | `com.codes_harvester.backend` | `com.codes_harvester.backend.dev` |
| Рабочие данные | каталог старого проекта | `.runtime/dev/` текущего проекта |
| Печать | настройки эталона | отключена по умолчанию |

DEV-копия не изменяет старый Native Host `~/.config/google-chrome/NativeMessagingHosts/com.codes_harvester.backend.json`, старую базу, заказы или настройки городов.

## Требования

- Linux;
- Google Chrome, Chromium или Brave;
- Python 3.12 или совместимая версия с модулем `venv`;
- доступ к личному кабинету Avito;
- для реальной печати — настроенный CUPS и команда `lp`.

## Первый запуск

Перейдите в проект и подготовьте виртуальное окружение:

```bash
cd /home/esaul/PycharmProjects/get-qr-code-avito
./scripts/bootstrap_dev.sh
```

Запустите DEV-backend вручную:

```bash
./scripts/run_backend_dev.sh
```

Процесс должен оставаться запущенным. Проверка из другого терминала:

```bash
curl http://127.0.0.1:8011/parse/ping
```

Ожидаемый ответ содержит:

```json
{"status":"ok","instance":"codes-harvester-dev","port":8011,"print_enabled":false}
```

Интерактивная документация API доступна по адресу <http://127.0.0.1:8011/docs>.

## Установка DEV-расширения в Chrome

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение».
4. Выберите каталог `/home/esaul/PycharmProjects/get-qr-code-avito/extension`.
5. Убедитесь, что появилось расширение **Codes Harvester DEV** с меткой `DEV` на значке.

Эталонное расширение отключать не требуется. Сообщения Chrome между расширением и его content script изолированы, а backend работают на разных портах.

После изменения файлов расширения нажимайте кнопку «Обновить» на его карточке в `chrome://extensions`, а затем обновляйте вкладку Avito.

## Автоматический запуск backend — необязательно

Для первых тестов удобнее держать `./scripts/run_backend_dev.sh` запущенным вручную. Чтобы DEV-backend автоматически запускался при открытии popup:

1. Найдите ID расширения **Codes Harvester DEV** на странице `chrome://extensions`.
2. Выполните для Google Chrome:

   ```bash
   ./scripts/install_native_host_dev.sh ID_ИЗ_CHROME chrome
   ```

   Для Chromium используйте `chromium`, для Brave — `brave`.

3. Полностью перезапустите браузер.
4. Остановите вручную запущенный backend сочетанием `Ctrl+C` и откройте popup DEV-расширения.

Скрипт создаёт только `com.codes_harvester.backend.dev.json`. Manifest эталонного приложения не перезаписывается.

## Как пользоваться

### 1. Синхронизация объявлений и городов

Эту операцию нужно выполнить до тестирования фильтра заказов по городу.

1. Откройте в Avito страницу «Мои объявления»: `/profile/pro/items` или `/profile/items`.
2. Откройте **Codes Harvester DEV**.
3. Нажмите «Синхронизировать объявления».
4. Расширение загрузит все страницы, а backend сохранит соответствие названий городам.

Сейчас распознаются только Москва и Энгельс. Одинаковые названия, найденные в разных городах, считаются конфликтными и не используются для фильтрации.

### 2. Сбор заказов и создание этикеток

1. Откройте `https://www.avito.ru/orders`.
2. Откройте popup DEV-расширения.
3. При необходимости включите фильтр «Собирать заказы только для города» и выберите город.
4. Нажмите «Собрать».

Обрабатываются только заказы со статусом «Отправьте заказ». Для каждого заказа извлекаются код, название, доставка и количество. Этикетки сохраняются в:

```text
.runtime/dev/orders/ГГГГ-ММ-ДД/
```

Кнопка «Открыть заказы за сегодня» открывает этот каталог. Кнопка «Проверить печать» в стандартном DEV-режиме только считает найденные этикетки и ничего не отправляет на принтер.

### 3. Анализ отзывов

1. Откройте страницу отзывов продавца Avito.
2. Нажмите «Собрать».
3. После сбора нажмите «Отправить отзывы».

Backend извлечёт названия товаров и покажет до четырёх наиболее частых. В итог попадают товары, встретившиеся не менее четырёх раз.

## Рабочие данные DEV

Все изменяемые данные находятся отдельно:

```text
.runtime/dev/
├── avito_dev.db
├── listings/listing_cities.json
├── logs/native_backend.log
└── orders/ГГГГ-ММ-ДД/*.png
```

Скопированные файлы `avito.db`, `backend/avito.db` и `backend/data/listing_cities.json` кодом DEV-backend не изменяются и могут использоваться как справочные.

## Настройки и реальная печать

Создайте локальный файл настроек:

```bash
cp .env.example .env
```

По умолчанию в нём задано:

```dotenv
AVITO_DEV_PRINT_ENABLED=false
AVITO_DEV_PRINTER_NAME=XP-DT426B
```

Для намеренного теста физической печати измените `AVITO_DEV_PRINT_ENABLED` на `true`, проверьте имя принтера и перезапустите backend. Popup станет красным и явно покажет, что печать включена.

## Тесты

После подготовки окружения:

```bash
.venv/bin/python -m unittest discover -s backend/tests -v
```

Тесты проверяют разбор городов, фильтрацию заказов, каталоги этикеток и защитный режим без физической печати.

## Частые проблемы

- **Backend не запустился.** Сначала выполните `./scripts/bootstrap_dev.sh`, затем `./scripts/run_backend_dev.sh`.
- **Native host не найден.** Проверьте ID именно DEV-расширения, повторите установку host и полностью перезапустите Chrome.
- **На порту 8011 другой сервис.** DEV-расширение проверяет поле `instance` и откажется работать с чужим backend. Не переключайте его на эталонный порт 8000.
- **Нет связи с content script.** На `chrome://extensions` обновите DEV-расширение, затем перезагрузите вкладку Avito.
- **Не найдены заказы.** Проект выбирает только заказы со статусом «Отправьте заказ».
- **После фильтрации осталось 0 заказов.** Сначала синхронизируйте объявления; название заказа должно совпасть с сохранённым названием объявления.
- **Автозапуск завершился ошибкой.** Лог находится в `.runtime/dev/logs/native_backend.log`.

## Удаление только DEV-копии из браузера

Удалите карточку **Codes Harvester DEV** в `chrome://extensions`. При необходимости удалите только DEV-manifest:

```bash
rm "$HOME/.config/google-chrome/NativeMessagingHosts/com.codes_harvester.backend.dev.json"
```

Файл эталона `com.codes_harvester.backend.json` оставьте без изменений.
